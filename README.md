# __CyberTest__ — Система тестирования по кибербезопасности и цифровой гигиене

## О проекте
> Система тестирования по кибербезопасности и цифровой гигиене — это backend-приложение (REST API), которое позволяет:

+ #### Менеджеру (преподавателю/администратору):
    + создавать тесты по темам кибербезопасности;
    + добавлять вопросы разных типов (одиночный выбор, множественный выбор, текстовый ответ);
    + назначать тесты студентам, группам, направлениям, курсам;
    + публиковать тесты по расписанию;
    + просматривать статистику и результаты.

+ #### Студенту (ученику):
    + просматривать доступные тесты;
    + проходить тесты (с ограничением времени и количества попыток);
    + отвечать на вопросы;
    + получать результаты и прогресс;
    + видеть свой рейтинг.

### Предметная область (кибербезопасность и цифровая гигиена) включает __темы__:
+ Парольная безопасность и двухфакторная аутентификация
+ Фишинг и социальная инженерия
+ Безопасность в социальных сетях
+ Защита персональных данных
+ Безопасность мобильных устройств
+ Wi-Fi безопасность
+ Основы криптографии
+ Цифровая гигиена (управление данными, резервное копирование)
+ Законодательство в сфере кибербезопасности 

Backend-приложение (REST API) для проведения тестирования студентов
по темам кибербезопасности и цифровой гигиены.

## Что такое REST в моём понимании
>__REST__ - это не протокол и не стандарт, это аббревиатура от REpresentational State Transfer и архитектурный стиль для распределенных гипермедиа-систем. На этапе разработки разработчики API могут реализовать REST различными способами. 

    Рой Филдинг впервые представил его в 2000 году в своей знаменитой диссертации. С тех пор это стало одним из наиболее широко используемых подходов для создания веб-API (интерфейсов прикладного программирования).
